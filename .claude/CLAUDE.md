# Project instructions

## 文档与代码保持同步（重要）

这是一个用于学习 agent memory 的教学项目，`README.md` 是它的门面，
读者主要靠 README 理解项目结构和用法。因此：

- **每次修改代码后，必须同步检查并更新 `README.md`**，让文档与代码始终一致。
- 尤其注意这些改动一定要同步到 README：
  - 新增 / 删除 / 重命名文件或目录（更新 README 里的目录结构树）
  - 改变模块、类、函数的名字或职责
  - 改变运行方式、依赖、或环境配置（如虚拟环境、安装命令）
- 改完后做一次检查：确认 README 里不再提到已删除或已改名的文件（例如用
  `grep` 搜一下旧名字），避免文档里残留失效的叙述。
